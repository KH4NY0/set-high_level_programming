# Python - Classes and Objects

An introduction to object-oriented programming in Python 3: classes, instances,
private attributes, getters and setters via `property`, and special methods.

## Files

| File | Description |
| --- | --- |
| `0-square.py` | An empty `Square` class |
| `1-square.py` | `Square` with a private `size` attribute |
| `2-square.py` | `Square` with type and value validation on `size` |
| `3-square.py` | Adds the public `area()` method |
| `4-square.py` | Exposes `size` through a property getter and setter |
| `5-square.py` | Adds `my_print()`, drawing the square with `#` |
| `6-square.py` | Adds a `position` property used as an offset when printing |
| `100-singly_linked_list.py` | `Node` and `SinglyLinkedList` with `sorted_insert()` |
| `101-square.py` | Makes a `Square` instance printable via `__str__` |
| `102-square.py` | Makes squares comparable by area |
| `103-magic_class.py` | `MagicClass`, reproduced from Python bytecode |
