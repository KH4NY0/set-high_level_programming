# Python - More Classes and Objects

Class attributes, static methods, class methods and the special methods
`__str__`, `__repr__` and `__del__`, plus a backtracking solution to the
N queens puzzle.

## Files

| File | Description |
| --- | --- |
| `0-rectangle.py` | An empty `Rectangle` class |
| `1-rectangle.py` | `width` and `height` as validated properties |
| `2-rectangle.py` | Adds `area()` and `perimeter()` |
| `3-rectangle.py` | Adds `__str__`, drawing the rectangle with `#` |
| `4-rectangle.py` | Adds `__repr__`, usable with `eval()` |
| `5-rectangle.py` | Adds `__del__`, printing `Bye rectangle...` |
| `6-rectangle.py` | Adds the `number_of_instances` class attribute |
| `7-rectangle.py` | Adds the `print_symbol` class attribute |
| `8-rectangle.py` | Adds the `bigger_or_equal()` static method |
| `9-rectangle.py` | Adds the `square()` class method |
| `101-nqueens.py` | Solves the N queens puzzle |
