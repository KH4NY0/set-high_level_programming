The ``3-say_my_name`` module
============================

Using ``say_my_name``
---------------------

Import the function from the module:

    >>> say_my_name = __import__('3-say_my_name').say_my_name

Printing a first and a last name:

    >>> say_my_name("John", "Smith")
    My name is John Smith

    >>> say_my_name("Walter", "White")
    My name is Walter White

The last name defaults to an empty string, leaving a trailing space:

    >>> say_my_name("Bob")  # doctest: +NORMALIZE_WHITESPACE
    My name is Bob

Empty strings are valid:

    >>> say_my_name("", "")  # doctest: +NORMALIZE_WHITESPACE
    My name is

Numbers inside a string are fine:

    >>> say_my_name("Agent", "007")
    My name is Agent 007
