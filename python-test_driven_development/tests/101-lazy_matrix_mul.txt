The ``101-lazy_matrix_mul`` module
==================================

Using ``lazy_matrix_mul``
-------------------------

Import the function from the module:

    >>> lazy_matrix_mul = __import__('101-lazy_matrix_mul').lazy_matrix_mul

Multiplying two square matrices:

    >>> print(lazy_matrix_mul([[1, 2], [3, 4]], [[1, 2], [3, 4]]))
    [[ 7 10]
     [15 22]]

Multiplying a 1x2 matrix by a 2x2 matrix:

    >>> print(lazy_matrix_mul([[1, 2]], [[3, 4], [5, 6]]))
    [[13 16]]

Multiplying a 2x3 matrix by a 3x2 matrix:

    >>> print(lazy_matrix_mul([[1, 2, 3], [4, 5, 6]], [[1, 2], [3, 4], [5, 6]]))
    [[22 28]
     [49 64]]

Multiplying by an identity matrix returns the original values:

    >>> print(lazy_matrix_mul([[1, 2], [3, 4]], [[1, 0], [0, 1]]))
    [[1 2]
     [3 4]]

Floats are supported:

    >>> print(lazy_matrix_mul([[1.5, 2.5]], [[2], [2]]))
    [[8.]]

Negative numbers are supported:

    >>> print(lazy_matrix_mul([[-1, -2]], [[1], [1]]))
    [[-3]]

Unlike ``matrix_mul``, the exceptions here come from NumPy itself, so the
messages depend on the installed NumPy version. The tests below check the
behaviour rather than the exact wording.

A scalar has too few dimensions:

    >>> try:
    ...     lazy_matrix_mul(1, 2)
    ... except ValueError:
    ...     print("ValueError raised")
    ValueError raised

    >>> try:
    ...     lazy_matrix_mul(None, [[1, 2]])
    ... except ValueError:
    ...     print("ValueError raised")
    ValueError raised

A string cannot be multiplied:

    >>> try:
    ...     lazy_matrix_mul("Holberton", [[1, 2]])
    ... except Exception:
    ...     print("exception raised")
    exception raised

    >>> try:
    ...     lazy_matrix_mul([[1, 2]], "Holberton")
    ... except Exception:
    ...     print("exception raised")
    exception raised

A non int/float element cannot be multiplied:

    >>> try:
    ...     lazy_matrix_mul([[1, "2"]], [[3], [4]])
    ... except Exception:
    ...     print("exception raised")
    exception raised

An empty matrix cannot be multiplied:

    >>> try:
    ...     lazy_matrix_mul([], [[1, 2]])
    ... except Exception:
    ...     print("exception raised")
    exception raised

    >>> try:
    ...     lazy_matrix_mul([[]], [[1, 2]])
    ... except Exception:
    ...     print("exception raised")
    exception raised

Rows of different sizes cannot be multiplied:

    >>> try:
    ...     lazy_matrix_mul([[1, 2], [3, 4, 5]], [[1], [2]])
    ... except Exception:
    ...     print("exception raised")
    exception raised

Matrices with incompatible shapes raise a ValueError:

    >>> try:
    ...     lazy_matrix_mul([[1, 2]], [[1, 2]])
    ... except ValueError:
    ...     print("ValueError raised")
    ValueError raised

    >>> try:
    ...     lazy_matrix_mul([[1, 2, 3]], [[1], [2]])
    ... except ValueError:
    ...     print("ValueError raised")
    ValueError raised

Missing arguments raise a TypeError:

    >>> lazy_matrix_mul([[1, 2]])
    Traceback (most recent call last):
    TypeError: lazy_matrix_mul() missing 1 required positional argument: 'm_b'

    >>> lazy_matrix_mul()
    Traceback (most recent call last):
    TypeError: lazy_matrix_mul() missing 2 required positional arguments: 'm_a' and 'm_b'
