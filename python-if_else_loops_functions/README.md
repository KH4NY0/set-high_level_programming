# Python - if/else, loops, functions

Introduction to conditional statements, loops and functions in Python 3,
plus one C task on inserting a node into a sorted singly linked list.

## Files

| File | Description |
| --- | --- |
| `0-positive_or_negative.py` | Says whether a random number is positive, zero or negative |
| `1-last_digit.py` | Prints and classifies the last digit of a random number |
| `2-print_alphabet.py` | Prints the lowercase ASCII alphabet |
| `3-print_alphabt.py` | Prints the lowercase alphabet without `q` and `e` |
| `4-print_hexa.py` | Prints 0-98 in decimal and hexadecimal |
| `5-print_comb2.py` | Prints 00 to 99, comma separated |
| `6-print_comb3.py` | Prints all combinations of two different digits |
| `7-islower.py` | `islower(c)` - checks for a lowercase character |
| `8-uppercase.py` | `uppercase(str)` - prints a string in uppercase |
| `9-print_last_digit.py` | `print_last_digit(number)` - prints and returns the last digit |
| `10-add.py` | `add(a, b)` - returns a + b |
| `11-pow.py` | `pow(a, b)` - returns a to the power of b |
| `12-fizzbuzz.py` | `fizzbuzz()` - classic FizzBuzz, 1 to 100 |
| `13-insert_number.c` | `insert_node()` - inserts a number into a sorted linked list |
| `lists.h` | Header for the linked list task |
| `100-print_tebahpla.py` | Prints the alphabet reversed, alternating case |
| `101-remove_char_at.py` | `remove_char_at(str, n)` - removes a character by index |
| `102-magic_calculation.py` | Reproduces a given Python bytecode |
